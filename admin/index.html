إدارة المحتوى

من القائمة الجانبية يمكنك فتح قسم الأعمال والمشاريع أو نصوص الموقع أو الإعدادات.
بعد اكتمال الربط الآمن ستظهر التغييرات في الموقع الفعلي.

مراحل الإكمال

١. تجهيز الواجهة — مكتمل مبدئيًا.

٢. ربط قاعدة بيانات وحفظ الصور — لم يُنفّذ بعد.

٣. تأمين دخول المدير — لم يُنفّذ بعد.

٤. الاختبار قبل النشر — بعد اكتمال الربط.

الأعمال والمشاريع

لا توجد مشاريع مرتبطة بلوحة التحكم حاليًا. سيُفعّل الحفظ ورفع الصور بعد ربط قاعدة البيانات وخدمة التخزين.
اختيار الملفات هنا تجريبي فقط؛ لن تُرفع الصور أو تُحفظ حتى تفعيل الربط.

نصوص الموقع

يمكنك رؤية الحقول وتجهيز النصوص، لكن لن تتغير واجهة الموقع المنشور قبل تنفيذ نظام الحفظ.

الإعدادات والربط

سنربط اللوحة بقاعدة بيانات وتخزين صور مع تسجيل دخول آمن للمدير. لا تضع كلمات مرور أو مفاتيح وصول داخل ملفات الواجهة.

قاعدة البيانات: غير مهيأة
تخزين الصور: غير مهيأ
تسجيل الدخول: غير مفعّل
الحفظ: متوقف حتى اكتمال الربط الآمن
